# Migration to TypeScript — litsearch-frontend

Goal: convert all 886 `.js`/`.jsx` files to `.ts`/`.tsx`, with `tsc --noEmit` clean and `vite build` green at every step.

Strategy: incremental, inside-out. `allowJs` stays on until the end so JS and TS coexist; `checkJs` stays off (JS is not type-checked). Each phase renames a layer, adds explicit types (no `any` leaks into new code), runs `npm run typecheck` + `vite build`, then checks its box.

Conventions for converted files:
- `.ts` for modules without JSX, `.tsx` for modules with JSX.
- Replace `PropTypes` (if any) with TypeScript interfaces.
- Type API payloads at module boundaries; prefer `unknown` + narrowing over `any`.
- Keep runtime behavior identical — types only, no refactors.
